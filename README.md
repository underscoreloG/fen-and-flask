# Fen & Flask

A cozy top-down pixel game in the browser: gather marsh herbs, brew potions in the back room of your shop, put them on the shelves at your own prices, ring up the evening's customers, fill the daily order pinned on the board, sleep, buy the next plot of marsh, and spend the rest on upgrades from the shop's catalog.

Controls: arrows move, X swing (or back in panels), C or Enter interact / confirm, V notebook, Esc pause, M mute. Gamepad: stick or d-pad, X swing, A confirm, B back, Y notebook, Start pause.

```bash
npm ci
npm run dev
```

Then open http://localhost:5345. `npm run verify` runs the type check, boundary check, tests and build.
